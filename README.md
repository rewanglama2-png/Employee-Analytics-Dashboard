# Employee Analytics Dashboard

## 📊 Project Overview

An interactive **Excel Employee Analytics Dashboard** created to analyze workforce data for **5,000 employees**.

The dashboard provides a clear view of employee distribution, salary, performance, attendance, and workforce demographics using interactive filters and visualizations.

## 🎯 Key KPIs

- **Total Employees:** 5,000
- **Average Salary:** ₹90,508
- **Average Performance:** 70
- **Average Attendance:** 79.8%

## 📈 Analysis Covered

The dashboard analyzes:

- Employee distribution by **Department**
- Employee distribution by **Designation**
- Employee distribution by **City**
- **Average Salary** by Department
- **Performance Status** distribution
- **Gender Distribution**
- **Attendance**
- Overall employee and salary metrics

## 🛠️ Tools & Techniques

**Tool:** Microsoft Excel

**Techniques Used:**
- Data Cleaning & Preparation
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Analysis
- Interactive Dashboard Design

## 🎛️ Interactive Features

The dashboard includes interactive slicers for:

- **City**
- **Department**
- **Performance Status**

These filters allow users to explore the employee data dynamically.
